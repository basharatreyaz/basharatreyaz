# Install your GitHub profile portfolio

1. Create a **public** repository named exactly `basharatreyaz`.
2. Upload `README.md`, the `assets/` folder and `.github/workflows/snake.yml`.
3. Open **Actions** and enable GitHub Actions if prompted.
4. Run **Generate contribution snake** once using **Run workflow**. It creates an `output` branch.
5. The contribution animation may take a few minutes to appear; it refreshes daily.

GitHub profile READMEs are Markdown-rendered and do not execute JavaScript. The animated header is an SVG; the typing effect and statistics use third-party image services. This package does not change your account bio, avatar or pinned repositories.
